# src/campaign — キャンペーン基盤

担当: **campaign-dev**（`.claude/agents/campaign-dev.md`）

フラグ、ルート分岐、世代継承（縁値・恒久離脱・客将繰り上げ）、研究配分、セーブ。

話ID・フラグID・キャラ名をコードに直書きしない。すべて `data/` のテーブル経由。
セーブは ADR-0001（バッテリーバックアップ＋シナリオ中途の複数ポイントでのオートセーブ）で決定済み。
PRG-RAM $6000-$7FFF を使う。**電源断耐性（二面バッファ、チェックサムを最後に書く）は必須要件**。
恒久的な死亡は選択イベント起因のみであり、戦闘では起きない（ADR-0005）。

実装開始は **P4**。
