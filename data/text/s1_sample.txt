; つかった字（ADR-0008 案A への じこけんさ／じどうけいそくの けっか）
; ============================================================
;
; ＜A＞＜B＞＜B2＞＜C＞ ぜんぶ あわせて つかった字 = 95しゅ
;
;   ひらがな 56字:
;     あいうえおかがきぎくぐけげこごさしじすずせそぞただちっつてでとど
;     なにねのはばびふまみむめもやゆよらりるれろわをん
;   カタカナ 29字:
;     イエオカキクサシズゼダトナハバヒビホマミムモヤラリルロワン
;   すうじ 4字: 1 2 4 8
;   きごう 6字: 「 」 。 、 ！ …
;   くうはく: ＜B＞＜B2＞＜C＞のみ
;
; → かんじ 0字。ADR-0008 案A の しゅうごうの そとに 出た字は 0。
;
; ＜ちゅうい＞ この 29字の カタカナは、ADR-0008 案B の「実用集合29字」とは
;   中身が ちがう。案B に 無い字を 11字 つかっている:
;     カ キ バ ヒ ビ ホ マ ム ヤ リ ワ
;   （カラクリ／ヒビキ／シバリ／ホムラ／ヤマ／ワ／ハトバ／ミナト などが これに あたる）
;   つまり 案B を えらんでいたら、この おきかえ案は そのままでは 通らなかった。
;
; ============================================================
; わかちがき の じっそく（21台詞 / ウィンドウ25行）
; ============================================================
;
;   ＜A＞ なし      : 261字  1行へいきん 10.44  さいちょう 16字
